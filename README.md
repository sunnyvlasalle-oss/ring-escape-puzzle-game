# Ring Escape

A relaxing and challenging ring puzzle game.

## Features
- Colorful rotating rings
- Touch and mouse controls
- Level progression
- Coins and rewards
- Undo and reset controls
- Local progress saving
- Mobile-friendly layout

## Play
Open `index.html` in a browser.
